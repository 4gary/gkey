Gaming mode

Auto-detect games
Anything installed in a Steam, Epic, Xbox or Riot games folder counts, except launchers, updaters and crash handlers.
How it works
  • Gaming mode is on only while a game window is in front. Launchers like the League client never count; League's match runs as League of Legends.exe.
  • A session lasts from the first time you focus the game until it closes.
  • Keys you press in games don't count toward typing speed or keys/minute; they count toward APM (actions per minute = keys + clicks).
  • Mark or unmark any app as a game in the Apps tab. Old data for that app moves over too.

What is recorded
  • Counts only. "E was pressed 412 times between 2 and 3 pm." The order of keys is never saved, so nothing you type (passwords included) can be rebuilt.
  • Which app was in front, by program name. Window titles are not saved.
  • Click positions in a coarse 96×54 grid, per day.
  • Bytes sent/received per network adapter, per hour.
  • GPU load, temperature and power, CPU power, and which programs used the GPU, per hour.
  • Nothing leaves your PC. gkeystrokes blocks its own outgoing connections, and the dashboard only answers requests from this computer, unless you turn on the phone link (view-only, needs its secret key). See Privacy proof above.
Not counted
Input while an administrator window is focused (Windows blocks it from normal apps).
